## [Unreleased]

- Research KPI tracking system

- GDP per capita analytics module

## [0.1.0] - 2025-01-15

### Added
- Core CHAMP-LM platform
- LLM ensemble orchestration
- Novelty and impact scoring engines
- Real-time data streaming from Binance
- Health monitoring with Prometheus
- Research signal confirmation pipeline
- KPI registry and management
- Prompt NFT support
- Composite index for KPI tracking
- Docker support for local deployment

### Components
- **Stream Manager**: Resilient WebSocket connections with backoff
- **LLM Orchestrator**: Parallel model execution with error handling
- **Research KPIs**: Publication readiness scoring
- **Health Monitor**: System metrics and service health checks
- **Merkle Logger**: Cryptographic audit trail of research rounds
